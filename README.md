# PROJECT MOON LORE — 세계관 안내자 AI 프로토타입 v16

Lobotomy Corporation / Library of Ruina / Limbus Company 세 작품을 포괄하는 비공식 팬 프로젝트입니다. `로보토미-...`로 시작하는 파일명도 로보토미 코퍼레이션 단독 자료라는 뜻으로 해석하지 않습니다.

## 실행
1. ZIP 압축 해제
2. 폴더에서 터미널 실행 후 `python -m http.server 8000`
3. 브라우저에서 `http://localhost:8000` 열기

## 이번 보강
- 보충 ZIP에 있던 PDF 5개를 모두 열어 텍스트 추출을 확인했습니다.
- 다섯 문서에서 총 157페이지, 약 201,742자의 텍스트를 추출했습니다. 페이지 내 텍스트가 긴 경우에는 검색 품질을 위해 구간을 더 나눠 총 256개 검색 항목으로 추가했습니다.
- 기존 요약 자료 553개를 유지하고, 보충 자료를 합쳐 `data/lore.json`에 총 1414개 항목이 들어 있습니다.
- PDF 발췌 항목마다 원본 파일명과 PDF 페이지 번호를 출처로 기록했습니다.
- 파일명에 `로보토미-`가 포함되어도 세 작품을 연결하는 프로젝트 문 세계관 관점에서 검색하도록 공통 태그를 부여했습니다.

## 자료 파일
- `data/lore.json`: 기존 요약 + PDF 페이지별/구간별 검색 자료
- `data/documents_manifest.json`: 전체 PDF 25개의 페이지 수, 텍스트 추출 상태 및 보강 항목 수
- `data/sources.md`: 처리 원칙과 파일별 추출 현황

## 사용량 제한 안내
사이트 코드에 설정되어 있던 데모 일일 20회 제한과 개인 API 모드의 표시상 100회 제한을 제거했습니다. 사이트 자체에서 질문 횟수를 차단하지 않습니다. 데모 모드는 API 호출 없이 키워드 검색·규칙 기반 답변을 생성합니다. 개인 API 모드는 Gemini 제공업체의 계정별 요청량·요금·모델 접근 제한을 그대로 따르며, 이 제공업체 한도는 사이트 코드로 해제할 수 없습니다.

## 중요 제한
텍스트 추출이 가능하다는 것은 PDF에 포함된 텍스트를 읽어들였다는 뜻이지, 원문 내용의 정오나 나무위키 문서의 해석이 공식 설정임을 검증했다는 뜻은 아닙니다. 답변에서는 문서의 서술과 추론을 구분해야 합니다. 데모 모드는 키워드 검색 기반의 제한적 요약이며, 보다 자연스러운 답변은 설정에서 Gemini 개인 API 키를 입력해 AI 모드로 사용할 수 있습니다.

## 출처/저작권
자료는 사용자가 제공한 비공식 참고 문서에서 추출했습니다. 공식 데이터베이스가 아니며, 문서 작성자의 해석·추측은 게임 내 확정 설정과 구분해 다루어야 합니다.

## v15 데모 모드 대화 맥락 개선
- 짧은 후속 질문(예: “그럼 왜?”, “그 사람은?”)에서 직전 사용자 질문과 답변의 핵심어를 검색어에 보충합니다.
- 검색 점수에서 제목과 태그의 일치도를 높이고, 본문 내 반복 출현 및 핵심어 동시 출현을 고려합니다.
- 같은 원본 문서의 인접 페이지가 검색 결과를 독점하지 않도록 출처별 결과 수를 제한합니다.
- 답변은 질문 의도(이유, 관계/비교, 설명, 후속 질문)에 맞춰 문장 선택과 서두를 조정하고, 출처를 표시합니다.
- 한계: 데모 모드는 여전히 규칙 기반이며 생성형 AI가 아닙니다. 맥락 단서를 활용한 검색·발췌 품질은 개선하지만, 개인 API 모드와 같은 추론 능력을 제공하지는 않습니다.


## v16 UI 개선
- 시작 화면의 표기를 `PROJECT MOON · WORLD ARCHIVE`로 변경했습니다.
- 대화 컨텍스트 설명에서 카르멘 관련 직접 스포일러를 제거하고, 세계관 기록을 안내한다는 중립적인 설명으로 수정했습니다.
- 채팅 첫 화면과 입력 영역에 스포일러 주의 문구를 추가했습니다.
- 우측 출처 카드의 긴 URL/문자열이 카드 영역을 벗어나지 않도록 줄바꿈과 너비 제한을 적용했습니다.
- 모바일 메뉴를 열면 배경 딤 레이어가 나타나고, 딤 영역 클릭 또는 Escape 키로 메뉴가 닫힙니다. 메뉴 항목을 선택해도 자동으로 닫힙니다.
